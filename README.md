## ◈ Featured Projects

<details>
<summary><b>◆ Store Intelligence — Retail Analytics Platform</b></summary>

<br/>

> An enterprise-grade, end-to-end retail intelligence pipeline that ingests live video from 9 CCTV feeds and transforms raw footage into actionable business metrics — visitor counts, dwell heatmaps, and a 4-stage purchase conversion funnel.

<div align="center">

| Attribute | Detail |
|-----------|--------|
| **Stack** | Python · YOLOv8 · OpenCV · Flask · SQLite · Docker · Kafka · FastAPI · Redis |
| **Scale** | 9 concurrent CCTV feed streams · Real-time multi-person tracking |
| **Performance** | ~30% reduction in manual store-ops overhead via idempotent ingestion engine |
| **Architecture** | Centroid-based Re-ID · ByteTrack · Zone heatmaps · POS-footfall correlation |
| **Deployment** | Docker Compose · One-command reproducible deployment · Containerized full stack |
| **Impact** | 4-stage conversion funnel: Entry → Zone → Billing → Purchase |

</div>

This project demonstrates deep system integration — ML models operating on live hardware feeds, stream processing with Kafka, caching with Redis, and a FastAPI analytics layer — all containerized for production parity. The idempotent ingestion engine ensures zero data loss across session reconstructions, while the zone-level dwell heatmaps provide spatial intelligence unavailable in traditional retail analytics tools.

All SDLC phases were completed: data preprocessing, model training, test-driven debugging, and production API deployment.
